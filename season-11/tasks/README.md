# Season 11 Tasks & Exercises

This folder contains practical tasks organized by week. Each week includes:

- **Lesson tasks** - Hands-on exercises for each lesson
- **Daily challenges** - 30-minute coding challenges for practice between sessions
- **Mini-projects** - End-of-week deliverables

## Folder Structure

```
tasks/
├── SUBMISSION_GUIDELINES.md     # ⚠️ READ THIS FIRST
├── week-01-web-foundations/     # HTML basics, environment setup
├── week-02-css-mastery/         # CSS fundamentals, layouts
├── week-03-tools-workflow/      # Command line, Git & GitHub
├── week-04-js-fundamentals/     # Variables, functions, control flow
├── week-05-dom-manipulation/    # DOM, events, user interaction
├── week-06-async-javascript/    # Promises, async/await, APIs
├── week-07-js-best-practices/   # Local storage, code quality
├── week-08-react-fundamentals/  # Components, props, state
├── week-09-react-advanced/      # Effects, routing, styling
├── week-10-backend-basics/      # Node.js, Express, REST APIs
├── week-11-database-auth/       # MongoDB, authentication
└── week-12-deployment/          # Full-stack integration, launch
```

## How to Use

1. **Before each lesson:** Review the task file to understand what you'll build
2. **During lessons:** Complete hands-on activities with instructor guidance
3. **Between lessons:** Work through daily challenges (30 min/day)
4. **End of week:** Submit your mini-project via GitHub

## Task Difficulty Levels

- 🟢 **Beginner** - Follow step-by-step instructions
- 🟡 **Intermediate** - Apply concepts with less guidance
- 🔴 **Challenge** - Solve problems independently

## 📋 Submission Guidelines

**Read the full [Submission Guidelines](SUBMISSION_GUIDELINES.md)** before submitting any work.

Key points:
- **Repository naming:** `iyf-s11-week-{number}-{your-github-username}`
- **Required files:** README.md (all projects), CONTRIBUTORS.md (team projects)
- **Team projects:** Use Pull Requests - contributions must be verifiable on GitHub
- **Submit:** Repository URL to Google Classroom
